# 接线与安装

## 参考硬件

| 部分 | 配置 |
| --- | --- |
| 随身端 | CBU5000V210 Tag，全向单天线 |
| 车载 UWB | CBU5000V210 Anchor，三天线接收阵列，当前参考板为 CBD5214 |
| 主控 | ESP32-WROOM-32 |
| 电驱参考板 | 微雪 Waveshare DDSM Driver HAT（A） |
| 执行机构 | 使用速度模式的伺服驱动轮，按左右轮组差速配置 |

电机具体型号由使用者选择。若其通信协议与当前适配器不兼容，应实现新的 `motor_driver.h` 接口。

Tag 和 Anchor 的天线职责及选型依据见[天线选型与测距测角原理](../docs/天线选型与测距测角原理.md)。全向 Tag 仍需要验证佩戴遮挡与极化；三天线 Anchor 当前以 PD12 单基线角度参与控制，不能据硬件数量推断已有三维定位。

## 信号接线

| 信号 | ESP32 参考引脚 | 说明 |
| --- | --- | --- |
| Anchor GPIO03 测量 TX | GPIO14 / UART2 RX | 115200 8N1，参考实现只接收 |
| 电机 UART TX | GPIO19 / UART1 TX | 接参考控制板的电机总线接口 |
| 电机 UART RX | GPIO18 / UART1 RX | 预留，当前不解析反馈 |
| USB 下载与日志 | GPIO1 / GPIO3 | 保留板载 USB 转串口用途 |
| 地 | GND | 主控与外部测量、驱动接口需要正确共地 |

独立 ESP32 开发板不能把 UART 引脚直接当 RS485 接口；应使用与目标驱动匹配的收发器和方向控制。当前适配器对应参考板的总线硬件。电机电源与 UWB/主控逻辑电源按实际板卡额定值接入。

## 安装与方向

Anchor 板卡竖直、Type-C 朝下、天线面指向主要跟随工作区。沿 FRONT 看，目标在左时应 A/X 为正。将 Anchor 相对底盘参考点的平移和偏角填写到车辆配置中。

电机 ID 不根据插线顺序自动推断。车轮悬空时核对配置中 ID 1 对应物理左侧、ID 2 对应物理右侧；正速度应让两侧均推动整车前进。四驱底盘额外配置两个唯一 ID。

## 首次使能检查

1. 验证两端 UWB 固件与安装姿态，观察前方、左前、右前数据。
2. 测量车辆几何并检查 RPM 能力，确认控制台 `driver_ready` 为真。
3. 轮子悬空并保持可直接断开驱动电源，低速验证直行和转向符号。
4. 关闭 Tag，确认超时后的停止请求；再验证手动停止和重启停止。
5. 完成方向与停止检查后，在无遮挡试验区域进行地面参数整定。
