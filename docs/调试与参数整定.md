# 调试与参数整定

## 观测链路

按“原始测量 → 安装变换与滤波 → 控制状态 → 下发轮速 → 真实运动”定位问题。先确认上一层正确，再检查下一层。日志中的下发 RPM 不能替代真实轮速或地面运动测量。

## 建议验证顺序

| 阶段 | 操作 | 预期证据 |
| --- | --- | --- |
| UWB 单独验证 | 固定距离，移动到左前/正前/右前 | 距离合理、左正右负、帧率稳定 |
| 停车观测 | ESP32 未使能，查看网页 | 原始与滤波目标可读，轮速零 |
| 悬空方向 | 从低速度能力开始，启动跟随 | 正前左右同向，左目标右轮更快 |
| 保护验证 | 关闭 Tag、手动停止、重启 | 停止请求及时出现，重启不自行运动 |
| 地面直行 | 目标沿正前方缓慢移动 | 实际速度与参数尺度一致，接近目标减速 |
| 地面转向 | 左右对称轨迹 | 转向符号正确，无长期单侧偏差 |
| 网络维护 | 停车后导出 CSV、设置距离、测试 OTA | 参数重启保留、升级后保持停止 |

## 参数调整与影响

| 参数 | 增大后的主要影响 | 应观察的量 |
| --- | --- | --- |
| 跟随目标距离 | 停车与恢复距离整体增大 | 原始/滤波距离、arrived 切换 |
| 距离增益 | 相同距离误差产生更大速度请求 | 追赶响应、刹停、输入波动 |
| 转向增益 | 相同偏角产生更大角速度请求 | 左右摆动、转向滞后、轮速差 |
| 角度死区 | 小角度变化更少触发修正 | 稳态偏差、直行摆动 |
| 最大轮速 | 提高输出能力上限 | 地面速度、RPM 上限及负载 |
| 最小转弯半径 | 期望弧线更宽、给定速度下转向能力降低 | 轨迹半径、目标偏角 |
| 有效轮距系数 | 相同角速度请求需要更大轮速差 | 四轮滑移底盘的实际转角 |
| 加速度 | 起步更快 | 起步轮速曲线、姿态与负载 |

轮径和机械尺寸按实测填写，不作为修补转向方向的调参手段。方向错误在安装配置或驱动映射修正。

## 常见现象

| 现象 | 检查顺序 |
| --- | --- |
| 左右转反 | 原始角度 → Anchor 朝向 → 安装变换 → 物理左右 ID → 电机方向 |
| 网页有值但不行驶 | 使能状态 → driver_ready → 目标工作区 → 数据年龄 → 恢复距离 |
| 直行摆动 | 原始角度噪声 → 死区 → 滤波 → 转向增益 → 左右轮实际速度 |
| 失联后停车慢 | 帧时间戳是否刷新 → 超时阈值 → 控制间隔 → 驱动制动响应 |
| 实际速度和设定不符 | 有效轮径 → 传动比 → 电机协议单位 → 地面滑移 |
| Timing fault | 控制间隔 → 同步网络请求/日志导出 → 串口占用 → 电机通道数 |

## 日志分析

停止后立即导出 `/api/log.csv`，避免 256 帧缓冲覆盖。运行：

```powershell
python tools/analyze_log.py follow-log.csv --output follow-report.html
```

报告分开显示原始/滤波距离、角度与下发 RPM，跳过未知值并保留状态统计。建议保存当时的车辆配置、跟随配置、负载与地面条件，保证下一次试验能够比较。
