## 待实车验收

- 新版目标距离与实际停车距离、减速响应。
- 实际安装变换、左/右 ID 和电机方向。
- 四轮滑移底盘有效轮距、真实转弯半径与负载能力。
- UWB 遮挡、多径、目标工作区与重新捕获行为。
- 微雪总线驱动初始化、制动与四通道运行时间。
- 网页操作、NVS 保存/重启恢复、实际 OTA 成功与失败过程。
- 网络阻塞、控制器异常、硬件断链下的系统级停止措施。

## 已知限制

当前没有电机反馈解析、障碍感知、物理车体碰撞检测、自动搜索或倒车行为。外形包络是几何诊断值；轴距不参与当前理想差速换算。日志环形缓冲只覆盖最近约 12.8 秒。当前 HTTP 维护接口面向可信局域网。

射频底层包含厂商预编译库，其内部实现源码不在本仓库。UWB 构建需要单独安装 Keil 工具链与设备包。
