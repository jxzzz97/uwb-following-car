# 车辆参数与底盘适配

## 参考点与单位

以差速驱动轴中心为车体参考点；四轮滑移转向配置使用轮组接地点构成的几何中心。`+x` 向左，`+y` 向前，正角度向左。长度用 cm，速度用 cm/s，角度用 deg，角速度用 deg/s，轮速用 rpm。

配置入口为 `firmware/esp32/config/vehicle_config.h`、`follow_config.h` 与 `board_config.h`。修改几何不需要重写 `followDemand()`。

## 机械与运动配置

| 参数 | 参考值 | 含义与实际用途 |
| --- | --- | --- |
| `body_length_cm` | 60 | 车体整体长度，参与外形旋转包络 |
| `body_width_cm` | 40 | 车体整体宽度，参与外形旋转包络 |
| `track_width_cm` | 36 | 左右轮接地点中心距离，参与差速换算 |
| `wheelbase_cm` | 24 | 前后轮轴间距，记录机械结构；当前差速公式不使用 |
| `wheel_diameter_cm` | 7.7 | 有效滚动直径，线速度与轮 RPM 的换算 |
| `anchor_left_cm` | 0 | Anchor 相对车体参考点向左的安装偏移 |
| `anchor_forward_cm` | 0 | Anchor 相对参考点向前的安装偏移 |
| `anchor_yaw_deg` | 0 | Anchor FRONT 相对车头向左偏转的角度 |
| `effective_track_scale` | 1 | 有效轮距 / 测量轮距，补偿四轮滑移转向的实际差异 |
| `max_wheel_speed_cm_s` | 60 | 每侧轮组最大线速度，按比例限制左右输出 |
| `max_yaw_rate_deg_s` | 70 | 跟随请求的最大角速度 |
| `min_turn_radius_cm` | 30 | 跟随请求采用的最小前进弧线半径 |
| `acceleration_cm_s2` | 35 | 正常行驶轮速增加速率 |
| `deceleration_cm_s2` | 70 | 正常行驶轮速降低速率；保护停车直接输出停止 |

参考值用于使工程配置完整，尚未证明适合其他底盘。车宽不能代替轮距，轴距不能代替车长。安装偏移的零值表示坐标参考点重合，实际安装不重合时应实测填写。

## 车长和车宽如何参与

`sweptRadiusCm()` 计算以外形中心为中心的矩形包络半径：

```text
R_envelope = 0.5 × sqrt(body_length_cm² + body_width_cm²)
```

该结果在启动诊断中输出，可供布置试验空间和未来碰撞检测使用。它以外形中心为基准；驱动参考点偏离外形中心时，需要额外计算偏心包络。当前跟随控制不根据环境距离检查这条包络。

## 换底盘的工作顺序

1. 测量外形、轮距、轴距、轮径与 Anchor 安装偏移。
2. 设置速度与加减速能力，检查电机减速比后的 RPM 是否超出驱动协议范围。
3. 核对物理左、右轮组的 ID 和正向。四电机使用四个唯一 ID，每侧设置两个通道。
4. 验证直行速度和转向方向，再标定有效轮距系数。
5. 在已确认的机械配置上整定跟随参数，记录配置与试验条件。

配置错误会阻止使能。几何的有效数值检查不会替代机械测量、负载能力或实际方向确认。
