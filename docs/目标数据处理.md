# 目标数据处理

## 原始测量与控制目标

`Measurement` 是一帧通过解析检查的 Anchor 测量，`Target` 是转换到车体参考点并经过滤波的控制目标。原始值用于定位输入问题，滤波值用于控制，两者的距离可能因安装偏移而不同。

| 字段 | 设计原因 |
| --- | --- |
| `timestamp_ms` | 保存完整有效帧的接收时间；读取快照不会刷新它 |
| `sequence` | 每个新有效帧递增一次，区分新测量和重复读取 |
| `valid` | 表达曾获得有效测量；使用时还必须检查数据年龄 |
| 原始距离、角度、X/Y | 保留通信输入，以便与变换、滤波结果比较 |
| `last_reject` 与计数 | 说明拒绝原因，避免把异常帧静默丢弃 |

## 串口检查

行缓冲 256 字节，溢出后丢弃至下一换行，避免截断帧的尾部被当成新测量。解析要求以 `DIST:` 开头，字段间使用 Anchor 当前的 `, X:` / `, Y:` / `, A:` 分隔形式。

检查包括：字段非空且为有限数值；距离 `(0, 5000] cm`；角度 `[-180, 180] deg`；X/Y 范围；`sqrt(X²+Y²)` 与 DIST 的差异不超过 `max(30 cm, 15% DIST)`。最近有效帧年龄不超过 500 ms 时，距离跳变超过 200 cm 或角度跳变超过 60° 被拒绝；超过重捕获窗口后允许建立新基准。

这些阈值继承原解析策略，属于接收完整性和粗异常检查；不构成对遮挡、多径或射频测量质量的完整判定。附加诊断字段目前不参与控制。角度用于范围和跳变检查，控制方向由 X/Y 在坐标变换后重新计算。

## 安装变换

令安装偏角为 ψ，平移偏移为 `(x₀, y₀)`：

```text
x_body = X × cos(ψ) + Y × sin(ψ) + x₀
y_body = Y × cos(ψ) - X × sin(ψ) + y₀
distance = hypot(x_body, y_body)
angle = atan2(x_body, y_body)
```

先旋转再平移。目标不在前方，或偏角超过配置的 80° 工作区时，输出无效目标并复位滤波。没有定位到前方的目标不会触发自动搜索或倒车。

## 四状态 Kalman 滤波

状态为 `[角度, 距离, 角速度, 径向速度]`，采用恒速度预测与角度/距离测量更新。源码沿用 `EKF_*` 命名，但当前实现是线性 Kalman 滤波。

每个控制周期预测一次，只有测量序号变化时更新测量，避免把同一帧重复计算成多次独立证据。NIS 门限为 16，连续 5 次创新拒绝后重新播种。Q/R 与初始协方差保留已有滤波实现的数值；过程噪声按周期加入，因此改变控制周期时要重新评估滤波参数。

数据年龄超过默认 300 ms 后清空估计；再次接收到目标时，以新测量重新初始化。未使能运动时仍处理目标，便于停车观察滤波效果。

## 验证与异常定位

比较原始值、滤波值、帧数、数据年龄和拒绝原因。原始值异常优先检查测量和通信；原始值正确而车体角度偏移，检查安装参数；输入稳定但滤波响应滞后，再分析 Q/R 与工作周期。主机测试覆盖格式异常、NaN、溢出恢复、跳变重捕获、重复帧与安装变换。
