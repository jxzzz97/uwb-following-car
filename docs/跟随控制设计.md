# 跟随控制设计

## 控制接口

输入为有效的车体坐标目标，输出 `Motion {forward_cm_s, yaw_deg_s}`。控制器使用前向距离跟随，不生成自主倒车请求。目标角度为左正右负，正角速度要求物理右轮快于左轮。

## 距离控制与停车滞回

默认目标距离 120 cm、停车阈值 120 cm、恢复阈值 135 cm。初始使能后进入到达滞回，目标超过恢复阈值再开始运动。正常距离请求为：

```text
error = max(0, filtered_distance - target_distance)
cruise_speed = min(max_wheel_speed, distance_gain × error)
```

`distance_gain_per_s=0.7` 表示每增加 1 cm 距离误差，增加约 0.7 cm/s 的巡航请求；最终输出还要经过转向和轮速约束。接近目标后逐渐减速。

原始变换距离或滤波距离任一个达到停车阈值，立即锁定到达并输出停止。恢复需要原始与滤波距离都超过恢复阈值，避免滤波滞后掩盖已经过近的目标。目标距离通过网页修改时，保持停车和恢复阈值相对目标的偏移。

`arrived_` 是行为状态，`target_distance_cm` 是期望值，二者分别保存。若只用一个瞬时比较结果，目标在边界波动时容易反复启动。

## 转向请求

角度死区默认 3°，死区之外按 `steering_gain_per_s=1.6` 生成角速度，再受最大角速度和距离相关能力限制：

```text
steer = sign(angle) × max(0, abs(angle) - angle_deadband)
yaw_limit = min(max_yaw_rate, cruise_speed / min_turn_radius)
yaw_request = clamp(steering_gain × steer, -yaw_limit, yaw_limit)
```

公式中的角速度和弧度换算在源码中显式完成。距离误差很小时，角速度能力也减小，避免近目标仍保持较高转向速度。

7° 以内使用完整巡航请求，7–42° 逐渐减小直行分量。随后根据 `|yaw| × min_turn_radius` 保留前进弧线分量，限制突然原地转向；左右轮均保持非负。42° 表示直行分量衰减终点，并不表示车辆在此角度必然停住。

## 输出约束

底盘模块按几何转换为轮 RPM，超过轮组能力时左右同比例缩放。正常轮速变化采用共同插值比例限制，以满足任一侧加减速能力并保留起步转向比例。保护停车绕过正常斜坡，直接向驱动下发停止请求。

最小半径约束作用于期望运动。逐侧禁止反转、轮速饱和和过渡限速可能改变最终运动；实际半径受底盘滑移与负载影响，不能将配置值视为实测转弯半径保证。

## 与原工程的关系

保留原系统的测量滤波、到达滞回、角度死区、大角度前进衰减和连续转向思路。旧版抽象速度、分段近距速度、左右交换及避障分支已从公开控制链移出；本版本采用物理单位和显式差速运动学，行为及参数不声称与旧实车版本完全一致。

## 整定依据

先确认测量与电机方向，再确定实际速度能力，最后整定距离增益与转向增益。增益增加通常让响应更快，也可能放大输入波动；死区增加可减少小角摆动，也会增加跟随偏差。每次修改记录场景、参数和原始/滤波/轮速日志。
