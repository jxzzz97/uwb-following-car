# 运行状态与保护机制

| 状态 | 进入条件 | 电机请求 | 恢复方式 |
| --- | --- | --- | --- |
| `disarmed` | 上电、主动停止、升级结束或撤销使能 | 零速制动 | 显式启动 |
| `signal_lost` | 没有测量或最近有效帧超过 300 ms | 零速制动 | 使能保持时等待有效目标 |
| `out_of_view` | 目标不在有效前方工作区 | 零速制动 | 目标回到有效区 |
| `arrived` | 到达停车区或尚未达到恢复距离 | 零速制动 | 原始及滤波距离均超过恢复阈值 |
| `following` | 已使能、有效目标、满足恢复条件 | 限幅及平滑后的轮速 | 持续观测 |
| `ota` | 通过 OTA 验证并开始升级 | 零速制动，撤销使能 | 完成重启或失败后显式启动 |
| `timing_fault` | 运动使能期间，控制间隔超过 150 ms | 零速制动，撤销使能 | 显式启动 |
| `config_fault` | 核心几何或控制参数无效 | 零速制动 | 修复配置并重新部署 |

硬件适配配置另通过 `driver_ready` 暴露。该标记表示配置检查通过，不表示收到了电机在线反馈。

## 数据时效

只有完整且有效的 UART 帧刷新测量时间戳。读取网页、访问日志、重复控制预测均不延长测量寿命。距离、角度异常被拒绝时，继续检查上一帧的真实年龄；到超时后停车。

## 控制周期与停止

控制主循环每 50 ms 更新。普通运动具有加减速约束；到达、失联、无效工作区、主动停止、OTA、调度故障统一通过停止路径。驱动在初始化和停止周期下发零速制动。

同步网页处理或串口发送会占用主循环时间。检测到超时只能在执行恢复后制动。若控制器断电、死机或驱动通信完全断开，本机软件不能继续发送停车帧；实际车辆应依据所用驱动的硬件失联保护和独立停止装置完成集成验证。

## 远程操作

运动与参数写入接口要求独立控制令牌，固件没有默认共享令牌。OTA 使用独立密码。网页状态与日志为同一局域网可读；当前 HTTP 无 TLS，部署边界为可信本地调试网络。USB 的 `arm` / `stop` 是本地控制接口。

导出 CSV 要求先停止，避免大数据传输阻塞正在运动的控制循环。重启和升级不会自动恢复运动使能。
